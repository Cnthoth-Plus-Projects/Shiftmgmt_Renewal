# 왜 새로 요청하지 않는가

이 6장에 필요한 **시각 요소가 전부 이미 있습니다.** 새로 만들 디자인 언어가 없습니다.

| 필요한 요소 | 이미 있는 곳 |
|---|---|
| 회색 막대 로딩(스켈레톤) | **12** 홈 로딩 |
| 잠금 아이콘 + 권한 없음 안내 + 비활성 버튼 + 사유 | **07** 실적 권한 없음 |
| 진행 표시 · "중단할 수 없습니다" 안내 | **05** 인테이크 진행 중 |
| 오류 3종 — 빨간 띠 · 칸 안 `사용할 수 없는 값` · 파란 안내 상자 | **10** 1-B 못 쓰는 값 |
| 1-B 본문 구조(팔레트 + 묶음별 설정 + 3개월 시뮬레이션) | **09** |
| 1-A 폼 배치 | **08** |
| 조별 배정 보드 | **19** |
| 앱 껍데기(좌측 메뉴 · 제목줄 · 상태줄) | **03 · 09** |

**10번을 다시 요청할 필요도 없습니다.** 09에 `근무 유형 팔레트`와 `패턴 설정` 표가 **둘 다 있으므로**, 10의 경고를 어디에 붙일지는 정할 것이 없습니다 — 팔레트 줄에 흐리게, 패턴 칸에 빨간 배경. **1:1로 옮겨집니다.**

색도 PNG에서 그대로 뽑아 씁니다.

# 공통 규칙 (6장 전부)

`내가-고칠-것_19장.md`의 「전 장 공통」과 같습니다. 요약하면:

- **좌측 메뉴** — `준비 / 운영 / 정산` 그룹 머리. **마법사 화면에도 있습니다**(10번엔 없었음)
- **하단 상태줄** 네 칸 — `● DB 연결됨 │ 최근 인테이크: … │ 대기 파일 3개 │ 최신`
- **역할 한국어** — 사용자 / 계획 담당 / 승인 담당
- **마법사 단계** 상단 가로 `1-A / 1-B / 1-C / 2` (08번이 정본)
- **조 이름 `A조·B조·C조`** · 직급 5개만 · `석간`·`휴게`·`묶음`
- 🔴 **`N/M` 숫자 진행률은 엑셀 접수·해석과 업데이트에만.** 그 밖은 `처리 중…`
- 🔴 **중단·취소 버튼 없음**
- 메뉴 배지 `128` (단 **B는 비움**)

# A. 마법사 `1-B 못 쓰는 값` — **09 + 10의 경고**

**바탕**: 09 그대로 (팔레트 · 묶음별 설정 + 패턴 설정 표 · 3개월 시뮬레이션 · 조별 인력 명단 · 좌측 메뉴 · 상단 가로 4단계 · 상태줄)

**얹을 것** (10에서 그대로 가져옴)

| 요소 | 붙는 자리 |
|---|---|
| 빨간 띠 경고 | 본문 맨 위 |
| 줄 흐리게 + `사용할 수 없음` | **`근무 유형 팔레트`** 의 `석간` 줄 |
| 칸 빨간 배경 + `사용할 수 없는 값` + ⚠ | **`패턴 설정`** 표에서 `석간`이 놓인 칸 |
| 파란 안내 상자 | 본문 아래 |

**상황**: `하루 교대 횟수`를 3회 → **2회**로 줄여 `석간`을 못 쓰게 된 상태

```
빨간 띠
  하루 교대 횟수를 줄여 '석간'을 더 이상 쓸 수 없습니다. 패턴에서 '석간'을 바꿔 주세요.

파란 안내 상자
  '석간'은 현재 하루 교대 횟수(2회)로는 사용할 수 없습니다.
  패턴 설정에서 '석간'으로 되어 있는 칸을 '주간' 또는 '야간'으로 바꿔 주세요.
```

**하단 버튼**: `[이전: 기본 설정]` `[입력 검토]` — **둘 다 활성**

- 🔴 값을 자동으로 바꾸지 않는다. 틀린 값을 그대로 두고 경고만
- 🔴 `[입력 검토]`를 막지 않는다 — 막으면 뭐가 잘못됐는지 볼 방법이 없어짐
- 🔴 `[저장]`·`[임시 저장]`·`[취소]` 없음. 앞길이 막히는 건 **다음 단계(1-C)** 에서
- `묶음별 설정`의 `하루 교대 횟수`는 `2회`

# B. 실적 관리 **로딩** — 03 + 12의 스켈레톤

```
탭        ② 승인 작업 열림 (03과 같은 탭)
필터 줄   자리는 있되 비활성
요약 숫자 대기 실적 · 재승인 필요 · 확인 필요 → 숫자 자리에 회색 막대
버튼      승인·반려·되돌리기·숨기기·원본 엑셀 열기 전부 비활성
표        열 머리는 보이고 줄은 회색 막대 15~17줄
          근무지(그룹)/사번/이름/직급/근무일/구분/근로유형/시작-종료/
          총/기본/연장/야간/시급/상태/경고   ← 15칸, `수당` 없음
배지      🔴 비움
```

- 뼈대는 보이고 **내용만** 회색 막대. 빈 화면 + 스피너 방식 금지

# C. 마법사 **로딩** — 08 + 12의 스켈레톤

```
단계      1-A 진행 중, 나머지 흐리게
본문      08의 폼 배치 그대로, 값 자리만 회색 막대
하단      [뒤로가기] [다음: 근무시간 설정] 둘 다 비활성
```

- 🔴 제목 옆 `● 저장되지 않음` **넣지 않음** (아직 입력한 게 없음)

# D. 마법사 **권한 없음** — 08 + 07의 잠금 배너

승인 담당이 근무지 등록 화면에 들어온 상태. **숨기지 않고 비활성 + 이유.**

```
본문 맨 위 (07의 잠금 배너 모양)
  🔒 근무지를 등록·수정할 권한이 없습니다.
     현재 권한(승인 담당)으로는 이 작업을 할 수 없습니다.

본문      08의 1-A 폼. 값은 들어 있되 전부 비활성
하단      [뒤로가기] 활성 ← 나가는 길은 열어 둠
          [다음: 근무시간 설정] 비활성
          옆 문구: 근무지 등록 권한이 필요합니다 (현재 권한: 승인 담당)
좌측 메뉴 `근무지 관리`도 그대로 보임 (메뉴에서 지우지 않음)
```

- 🔴 비활성 사유는 **항상 보이는 글자**. 마우스 올려야 보이는 방식 금지

# E. 마법사 **처리 중** — 19 + 05의 진행 안내

마지막 단계에서 `[완료]`로 근무지와 배정을 저장하는 동안. **두 번 눌리면 안 되는 자리.**

```
본문      19의 조별 배정 보드. 내용은 보이되 살짝 흐리게 덮음
안내      ⟳ 저장하는 중입니다…
          근무지와 인력 배정을 저장하고 있습니다. 이 화면을 닫지 마세요.
하단      [이전 단계] [입력 다시 검토] [근무표로 이동] [완료] 전부 비활성
          [완료]는 도는 표시 + `저장 중…`
```

- 🔴 숫자·퍼센트·취소 버튼 없음

# F. 홈 **처리 중** — 01 + 한 줄만 스피너

홈에서 수당 계산·문서 재출력·조기 지급일 지정을 실행하는 동안.

```
바탕      01 그대로 (진행 막대 3개 · 대기 실적 현황 · 지금 해야 할 일)
바뀌는 곳 실행한 그 줄만:   수당 계산   ⟳ 처리 중…     (그 줄 버튼만 비활성)
나머지    평소대로
```

- 🔴 **화면 전체를 덮지 않는다.** 그동안 다른 걸 볼 수 있어야 함
- 진행 막대 문구는 그대로 — `준비 7/10 근무지 (현재 배정 기준)` · `운영 13/20 단계` · `월 정산 2/3 단계`
