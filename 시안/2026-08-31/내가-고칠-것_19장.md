# 🔴 옮길 때 지킬 것

1. **실적 표 한 줄 = 사원 1명 × 근무일 1일.** 근무지별 그룹으로 묶음. 열은 **12개**(`수당` 없음)
2. **`수당` 금액은 04 행 상세·15 비교 패널에서만.** 승인 전이면 `승인 후 계산됩니다`
3. **`되돌리기`는 파일 단위** — 툴바에만. 확인 모달에 *"승인 기록과 계산된 수당이 함께 지워지며 되살릴 수 없습니다"*
4. **`목록에서 숨기기`는 되돌릴 수 없음** — `숨긴 행 포함해서 보기` 같은 복원 UI **만들지 않음**. 비활성 여부·사유는 서버가 주는 값을 그대로 사용
5. **날짜는 고르는 즉시 반영** — `[확인]`·`[적용]` 버튼 금지
6. **모달은 Esc + 포커스 트랩.** `window.confirm/alert` 금지
7. 한 파일 **30KB 넘기지 않게** 쪼갬
8. **다 만든 뒤 실제로 띄워 캡처 + 클릭 자동 검증** (절대 규칙 12)
