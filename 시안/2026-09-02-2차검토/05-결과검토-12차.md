## §3 D9 설계(요청서 §K 792행 "실행 시작 후 Esc 불가·닫기 불가. 진행 표시만")

- 모달(또는 헬퍼)마다 `processing` 플래그 1개. 실행 클릭 → `processing = true` + 닫기 계열 버튼(취소·✕·돌아가기) `disabled` + 실행 버튼 `disabled` + 라벨 `…중...`(+ 라이브 리전). `closeModal`/`closeAll`/`backToPreview`는 `processing`이면 무시. `keydown Escape`는 `preventDefault` 후 `processing`이 아닐 때만 닫는다.
- 완료 콜백(데모 600·800ms)에서만 `processing = false` → 버튼 해제 → 닫기 → opener 복귀. **취소 API를 만들지 않는다**(Codex 최소 수정안 그대로).
- 미리보기([미리보기] → `미리보기 생성 중...`)는 조회이므로 잠그지 않는다(미리보기 → 실행 짝에서 잠금은 실행 쪽).
- 같은 결함이 ⑤ 재검증에서 C1~C4·T4·R4·A4·A5·O10(5파일 9모달)에도 재현됐다 → ④ R27(같은 설계).
