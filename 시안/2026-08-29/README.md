## 정리하면서 눈에 띈 것 (정식 검수는 아직)

> 아래는 **파일을 정리하며 눈에 걸린 것**이고, `11-디자인-요청서.md`의 검수 체크리스트를 항목별로 대조한 **정식 검수는 하지 않았다.** 정식 검수는 별도로 진행한다.

### 형식 차이

요청서는 **HTML 파일**을 요구했고(파일명 `03-home.html` 등, 최소 JavaScript 동작 포함), 받은 것은 **PNG 이미지 30장**이다.
이미지로는 **클릭·포커스·Esc·가로 스크롤·밀도 토글 같은 동작을 검증할 수 없다.** 절대 규칙 12(“UI는 반드시 실제로 띄워서 검증한다”)를 이 단계에서 만족시키지 못한다.
→ **레이아웃·정보 구조·문구 검수는 이미지로 가능**하다. 동작 검증은 HTML을 받거나 구현 단계에서 해야 한다.

### LOCK 문서와 맞는 것으로 보이는 부분

- 홈 진행 막대가 **`준비 7/10 근무지 (현재 배정 기준)` · `운영 13/20 단계` · `월 정산 2/3 단계`** 로 단위·표기까지 일치
- 준비 막대 아래 **보조 문구**("이번 달 중간에 배정이 끝난 인원은…")가 들어감
- **`이번 달 대기 실적 현황`** 블록이 건수로만 있고 퍼센트가 없음. **`대기 실적 그룹 3개`** 표기도 일치
- **`근무지 연결 불가` / `중복 이름으로 연결 불확정`** 이 두 줄로 분리됨
- 권한 없음 상태(07)가 **숨김이 아니라 비활성 + 사유 표시**
- 이탈 모달(20) 버튼이 **`계속 편집` / `변경 버리고 나가기`**
- 고아 승인행(14)이 **홈이 아니라 실적 관리 화면 안**에 있음
- 인테이크에만 `34/120` 수치 진행률이 있음

### 🔴 확인이 필요한 부분

1. **`08-performance.html` 한 화면이 서로 다른 4가지 구조로 그려졌다.**
   - 03: 탭 `접수·복구 / 승인 작업 / 재승인·비교`
   - 04: 탭 `실적 제출 / 승인 작업 / 승인 완료` + 우측 상세 패널
   - 05: 아코디언 `① 접수·복구` 접기/펴기
   - 06: 화살표 단계 `접수·복구 / 검증·매핑 / 승인·완료`
   - 07: 카드 탭 `준비 작업 / 승인 작업 / 확정 및 보고`
   → **같은 화면인데 탭 이름과 구조가 5가지다.** 하나로 정해야 한다.
2. **좌측 메뉴 구성이 장마다 다르다.** 03·13·14·15·16에는 `근무지 관리`가 없고, 07에도 없다. 21에는 그룹(준비/운영/정산/관리)이 있는데 나머지에는 없다.
3. **26~30(로그인)에 로그아웃 버튼이 있다.** 로그인 전 화면에 로그아웃은 성립하지 않는다.
4. **27(로그인 오류)에 `회원가입` 링크가 있다.** 이 제품에 회원가입 기능은 없다 — 가짜 UI 금지 위반 소지.
5. **03의 상태 배지에 `수당 미지급`, 13에는 `수정 미처리`** 로 같은 자리 문구가 다르다.
6. 04의 상세 패널에 **`증적 야간근무_증적.jpg` 첨부**가 있다. 실적 증빙 파일 첨부 기능은 능력 매트릭스에 없다.

→ 위 6건은 **정식 검수에서 근거와 함께 확정**한다.
