## §2. 공통 제작 규칙

1. **가짜 UI 금지** — 모든 버튼·링크는 §각 상태의 동작 정의 표에 있는 것만. 표에 없는 조작 요소를 추가하지 마라. ① 기각 X1~X13(`01-초기확인.md`)의 요소는 **재등장 금지**.
2. **빈 상태**는 "없습니다"로 끝내지 않는다 — 일러스트(1차 C6 규격: 원 96px `#EEF1FB` + 아이콘 40px accent + 장식 원 2, aria-hidden) + 원인 한 줄 + **다음 행동 버튼**.
3. **권한 없음**은 숨기지 않는다 — 버튼 `aria-disabled="true"` + `aria-describedby`로 사유 연결 + 사유 텍스트 **12px 항상 표시**. 클릭·Enter·Space 전부 무반응이어야 한다.
4. **처리 중** 상태의 실행 버튼은 라벨 교체(`저장 중...`) + `disabled` + 중복 클릭 차단.
5. 모달 공통: 딤 `rgba(0,0,0,.4)` · Esc 닫기 · Tab/Shift+Tab 포커스 트랩 · 닫힌 뒤 **opener로 포커스 복귀** · 열려 있는 동안 배경 `aria-hidden` — 닫을 때 **전부 원상 복원**(1차 G3 규격). `window.confirm/alert/prompt` 금지.
6. 표: 표머리 고정 개념(시각 표현) · 정렬 화살표는 정렬 기준 열에만 · 줄바꿈 대신 가로 스크롤(`overflow-x`) · 행 수는 상태별 명세를 따르고 **명세보다 임의로 줄이지 마라**.
7. 날짜 입력 UI는 "선택 즉시 반영" 전제로 그린다 — 별도 [확인] 버튼 금지. 직급이 나오는 곳은 **사원/대리/과장/차장/부장 5종만**.
8. 최소 JS 동작(각 상태 명세의 "동작"): ☰ 접기/펼치기(1차 복제) · 모달 열기/닫기/트랩/복귀 · 토스트 표시 · aria-disabled 차단 · 사유 입력 게이트 · 조 순서 이동. 그 외 동작은 구현하지 않는다(정적 시안).
9. 문구 전부 한국어. 영문 에러 코드·영문 역할명 노출 금지(역할 배지: `관리자`/`승인 담당`/`계획 담당`/`사용자`).
10. 데이터는 §D 마스터 데이터 카드만 사용. **임의 수치·임의 인명·임의 문구 창작 금지.**
