## §2. 공통 제작 규칙

1. **가짜 UI 금지** — 각 화면 절의 **동작 정의 표**(요소·누르면 일어나는 일·창구·권한/실패)에 있는 조작 요소만 그린다. 표에 없는 버튼·링크 추가 금지. X1~X13 재등장 금지. **오타·문구 드리프트 금지**(X12) — 이 지시서의 문구를 글자 단위로 옮긴다.
2. **빈 상태** = 일러스트(§1 정본) + 원인 한 줄 + **다음 행동 버튼**(전 빈 상태 필수 — R6 포함).
3. **권한 없음** = `aria-disabled="true"` + `aria-describedby` 사유 연결 + 사유 12px **항상 표시**. 클릭·Enter·Space 무반응.
4. **처리 중** = 라벨 교체 + `disabled` + 재클릭 무시. 되돌릴 수 없는 동작(A5·R4·T4·O10·E6 실행) 전부 적용.
5. 모달: 딤 `rgba(0,0,0,.4)` · Esc · 포커스 트랩 · **opener 포커스 복귀 + 배경(aria-hidden·차단) 완전 원상 복원**. `window.confirm/alert/prompt` 금지. **모달이 담긴 파일에는 opener가 같은 파일 안에 있어야 한다** — 실제 opener가 다른 파일이면 데모 트리거 버튼(`[○○ 열어 보기]` + 캡션 12px `데모용 — 실제로는 ○○ 화면의 [△△]가 엽니다`)을 둔다. C2·C3·C4 확인창 폭은 C1과 동일 **420px**.
6. 표 발췌 규칙(요청서 v1.4 정본 — **용량 상한이 행 수보다 우선**): 목록 표는 **6~8행 발췌**를 기본으로 하고 표 머리에 **`전체 N건 중 M건 표시`를 반드시 병기**한다(절대 규칙 5 — 조용한 잘라내기 금지). 예외: R1(규칙 7 줄 순서 검산용 — 14명 전원)·O9(18항목 전량). 그래도 51,200B를 넘으면 **행을 몰래 줄이지 말고** §H-5에 초과 사실과 취한 조치를 보고한다.
7. 날짜 입력 = 선택 즉시 반영(확인 버튼 금지). 직급 = **사원/대리/과장/차장/부장** 5종만. 고용형태 표기 = `정규직`/`BP(외부인력)` 2종(§D). 재직 상태 = `재직`/`휴직`/`퇴직`.
