- [D17] **못 쓰는 선택값을 자동 교체하지 않는다** (Codex 지적 반영). `사용할 수 없는 값` 표시 + 저장 차단 + 사용자 재선택. 절대 규칙 A-5("데이터를 조용히 바꾸지 않는다")가 `07` B-2의 "자동 교체" 문구보다 우선한다.
- [D18] **계산 규칙이 정의되지 않은 진행률·건수는 가짜 UI**로 간주해 만들지 않는다. 홈 진행 막대·할 일 목록의 창구 매핑은 `10-화면설계-초안.md` §5에 명세.

- [D21] **시안과 함께 「동작 정의표」를 받는다** (2026-08-29). 누를 수 있는 요소 전부에 대해 `누르면 일어나는 일 / 데이터 출처 / 권한 / 실패 상태`를 적게 하고, **채울 수 없는 요소는 화면에서 지운다.** 1차에서 가짜 UI 2건(엑셀 다운로드·증적 내려받기)이 늦게 발견된 원인이 이 표의 부재였다.
