# 교대근무관리 시스템 1.0.0

새 PC에 처음 설치하는 첫 정식 Windows x64 배포입니다. Node24 실행 환경을 포함하며 Google Chrome은 별도로 설치해야 합니다.

- 운영 관리 세부 카테고리, 공통 메뉴 위치·표·밀도, 시스템/다크 테마 및 작은 창 대시보드 개선.
- 실적 오류는 원본 Excel을 수정해 다시 가져오는 업무 흐름으로 정리. 승인 취소 전 승인·계산 원문과 사유를 이력에 보존하고 JSON3 백업으로 유지.
- 품의서·별첨1·별첨2 A4 출력과 양식 편집/별첨2 제목 배치 개선. 근무표 샘플은 Excel로 생성.
- 첫 설치·바탕 화면 바로가기·실행/종료 도구, 모든 배포 파일의 SHA256, Node/글꼴/실행 의존성 라이선스 포함.
- 정식 빌드는 테스트 계정 자동입력 버튼을 비활성화하며 첫 실행 창에서 기존 최초 관리자 로그인 정보와 비밀번호 변경 절차를 안내합니다.

ZIP을 압축 해제하고 INSTALL.cmd를 실행한 다음 바탕 화면 바로가기를 사용합니다. 설치와 자료 보호 절차는 ZIP의 설치안내.txt 또는 [새 PC 설치 안내](fresh-install.md)를 확인해 주세요.

기존 설치나 데이터가 있으면 덮어쓰지 않습니다. 기존 V3/V4 이관, 자동 업데이트, 다른 PC의 원격 접속은 이 패키지 범위에 포함하지 않습니다. JSON3 백업은 구판에서 복원할 수 없습니다. 프로그램에 들어 있는 초기 계정 연락처·기준값은 운영 전에 확인해야 합니다.

검증: 빌드, 타입/규칙/전체 단위 시험, 코드 지도, 모듈 smoke 및 격리 TEMP의 실제 Windows 설치·Chrome 로그인·첫 비밀번호 변경·정상 종료/재시작과 파일 변조/기존 설치 거절을 수행합니다. 최종 실행 결과와 ZIP 해시는 릴리즈 첨부의 검증 기록에 고정합니다. 실제 설치 대상 PC의 설치/운영 확인은 별도 단계입니다.

유지보수자는 고정된 커밋에서 npm ci 후 npm run release:package -- [새 출력 폴더] 로 빌드할 수 있습니다. 설치 검증은 npm run release:smoke -- [ZIP 절대 경로] 입니다. npm run release:check 는 소스가 커밋되어 있고 같은 버전 태그가 생성되기 전에 실행합니다. 원본 엑셀/DB/화면 검증 자료는 공개 릴리즈에 포함하지 않습니다.

포함된 Node 바이너리는 [Node 공식 배포 해시](https://nodejs.org/dist/v24.19.0/SHASUMS256.txt)와 비교하고 [Node 라이선스](https://github.com/nodejs/node/blob/v24.19.0/LICENSE) 및 글꼴 라이선스를 함께 제공합니다. 실행 의존성은 package-lock.json에 고정합니다. ZIP은 Windows 코드서명된 설치 프로그램이 아니므로 SHA256도 함께 확인해 주세요.
