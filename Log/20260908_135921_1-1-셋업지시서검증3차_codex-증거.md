## 4. 추가 발견 — favicon 404

v1.2의 `index.html` 명세와 파일 트리에는 favicon 선언이나 파일이 없다. 설치된 Chrome 152.0.7977.82를 Playwright로 실행해 같은 CSP의 최소 페이지를 열어 실측했다.

```text
favicon 없음:
server requests = ["/", "/favicon.ico"]
console = error "Failed to load resource: the server responded with a status of 404 (Not Found)"

<link rel="icon" href="data:,"> 있음:
server requests = ["/"]
console = []
```

favicon 요청은 Playwright `page`/`browserContext`의 response 이벤트에는 잡히지 않았지만 Chrome 콘솔에는 404 오류로 기록됐다. 따라서 §1 완료 기준 4의 “콘솔 오류 0·응답 400 이상 0”과 §1 완료 기준 10/§3 `capture-screen.mjs`의 “콘솔 오류가 하나라도 있으면 종료 2”를 현재 문안 그대로 구현하면 캡처가 실패한다.

추가 파일 없이 §4 `index.html` head에 `<link rel="icon" href="data:,">`를 명시하면 실제 Chrome에서 favicon 요청과 콘솔 오류가 모두 사라졌다. 현재 CSP의 `img-src 'self' data:`에도 부합한다. 이 한 줄과 이를 확인하는 브라우저 검증을 v1.3에 넣어야 한다.
