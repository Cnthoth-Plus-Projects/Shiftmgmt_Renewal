## 3. 정본

**R16 — 상태 알림 요소의 자리 (⑤ 정정)**: 6차 지시 R14-c의 "`.page-content` 첫 자식"은 틀렸다. ① `00-shell-2` S4~S6의 `<main class="page-content">`는 스켈레톤 무대라 **정적 `aria-hidden="true"`** 이고 ② T4·E6·R4·A5·O10의 처리 중 데모는 **확인 모달 안에서 실행되며, 모달이 열린 동안 `app-body`·`header-bar`가 `aria-hidden="true"`** 가 된다(N1 정본 — 모달 스크립트 `appBody.setAttribute('aria-hidden','true')`). 두 경우 모두 `main` 안의 `role=status`는 보조기기에서 숨겨져 낭독되지 않는다. 정본 자리 = **`.app-window`의 직계 자식으로 `.app-body` 바로 앞**(모달 오버레이도 `.app-window` 직계라 서로 형제 — 어느 aria-hidden에도 걸리지 않음). sr-only라 레이아웃 영향 0. 마크업·id·JS 1줄은 6차 그대로.
판정 방법(회신에 적을 것): 7개 `#live-*`에 대해 정적으로 `el.closest('[aria-hidden="true"]') === null`, 그리고 **해당 확인 모달을 열고 처리 중 버튼을 누른 뒤에도** `closest('[aria-hidden="true"]') === null` + `textContent === '처리 중: …'` 7개 전부.

**R17 — 포커스 링 증빙**: O1의 **편집 가능** 입력(readonly 아닌 것 — 예 `공휴일 API 주소` 또는 경고 기준 숫자 입력)에 Tab 또는 클릭으로 포커스를 둔 상태에서 캡처. 화면에 **2px 파란(`#3E56B6`) outline** 이 보여야 하고 `md5 focus-o1.png ≠ md5 o1.png`. 회신에 두 md5를 적는다.

**R18 — S3 재접힘 title**: `00-shell-1.html` 680행을 `if (el.textContent.trim() && !el.classList.contains('nav-badge')) el.parentElement.setAttribute('title', el.textContent.trim());` 로(빈 문자열 span — S3의 `nav-badge-dot` — 은 건너뜀). 정적 `nav-badge-dot`는 이 파일 S3에만 있으므로 다른 18파일의 같은 스크립트는 **손대지 않는다**. 판정: S3에서 ☰ 펼침 → 접힘 후 nav 7개 title 전부 존재(`실적 관리` 포함).
