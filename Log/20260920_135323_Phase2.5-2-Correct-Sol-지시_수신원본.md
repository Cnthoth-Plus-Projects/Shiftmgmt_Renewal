1. `clean()`은 boolean false를 보존한다. undefined/null/빈 문자열/의미 없는 빈 object와 false를 구분한다.
2. scrub은 semantic group별 명시 주소/범위 manifest로 만들고 actual-value blacklist를 제거한다. manifest 안 값이 scrub 후 모두 빈 값인지 구조적으로 검사한다.
3. generator/runtime 모두 worksheet/canvas/logo/columns/rows/merges/cells/value/style 타입·범위·중복·주소를 검증한다. 오류에는 layout key와 field path를 포함한다.
4. `--write`는 최종 5 bytes를 메모리에서 만든 뒤 schema/scrub 검증하고, 같은 filesystem staging에 모두 쓴 후 교체한다. 교체 중 실패하면 기존 bytes를 전부 복구하고 temp/backup을 정리한다. `--check`는 mkdir/write 0.
5. 수정 generator로 JSON 5개를 재생성하며 수동 편집하지 않는다.
6. parity helper는 false를 보존하는 recursive normalizer로 cell tagged values, merge/master, column/row width/hidden/outline, 전체 font/alignment/border/fill/numFmt/protection, worksheet properties/views/pageSetup/margins/headerFooter/printArea를 비교한다.
7. template1/2 unlocked 셀은 실제 write/reopen 후에도 false임을 assert한다. 대표 BA11만 비교하는 대신 full parity가 전체를 잡게 한다.
8. 기존 test 6 안에서 이미지 수, oneCell, tl/br를 확인하고 resolver null의 문서별 오류를 확인한다. `try/finally`로 seam을 null 복원한다.
9. 기존 test 7 안에서 unknown key와 최소 2개 corrupt definition을 검증한다. 새 it 금지.
10. schedule writer는 valid layoutKey 또는 variant 하나를 요구한다. 누락/invalid/충돌은 쓰기 전에 오류.
11. attachment2는 canonical `별첨2/B1/G2/row5`, prototype 13/86을 사용한다. profile 좌표를 읽지 않으며 styleSpec은 유지한다.
12. test 13-a/b에 `해당 없음`, 빈 금액, 잔여 sample 값 0 assertion을 추가한다.
13. test 14에서 attachment2를 실제 생성하여 2개 이상 근무지 상세/소계/마지막 총합과 금액을 확인한다. public export 우선; 불가피한 test alias는 로직을 복제하지 않는다.
