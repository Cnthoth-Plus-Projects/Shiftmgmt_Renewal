### 2. DISAGREE 항목

#### D1. 파일 전체 승인 뒤 표 상태가 바뀌지 않음

- 파일·위치: `시안/2026-08-31-1차HTML/08-performance-3.html:721-733`
- 심각도: **중대**
- 재현: P6에서 `[파일 전체 승인]` 실행 → 완료 → `[닫기]`. 칩·메뉴·라이브 영역은 `128→77`로 바뀌지만 본사 7행 상태 배열은 실행 전후 모두 `승인 / 대기 / 재승인 대기 / 승인 / 대기 / 반려 / 대기`로 동일했다.
- 사유: 지시서 §7-6은 본사 파일의 대기 행을 승인 상태로 바꾸도록 요구한다. 현재 화면은 총계와 행 상태가 서로 모순된다.
- 수정 방향: 완료 처리에서 선택 파일에 속한 **대기 행만** 승인 배지로 갱신하고 관련 ARIA 상태를 함께 동기화한 뒤 칩·메뉴·라이브 영역을 갱신한다.

#### D2. 단건 승인 실행의 재클릭 차단 가드가 없음

- 파일·위치: `시안/2026-08-31-1차HTML/08-performance-3.html:692-699`
- 심각도: **중대**
- 재현: 단건 승인 확인 버튼은 실행 전후 `disabled=false`이며 busy/idempotency 가드가 없다. 페이지 컨텍스트에서 확인 핸들러를 연속 호출하면 두 번째 호출도 실행된다. 일반 포인터 클릭은 첫 호출에서 모달이 즉시 숨겨져 재클릭하기 어렵지만, 지시서 §7-5의 명시적 `실행 중 재클릭 차단`은 구현되지 않았다.
- 수정 방향: 핸들러 첫 줄에 실행 중 가드와 즉시 버튼 잠금(`disabled`/`aria-busy`)을 두고, 중복 이벤트는 무시한다.

#### D3. `aria-disabled` 사유 연결이 끊기거나 없음

- 파일·위치:
  - `05-sites-wizard-3.html:572-573` — W5 `[다음 단계]`의 `aria-describedby="w5-err-desc"` 대상 ID가 없음
  - `05-sites-wizard-3.html:755-758` — W6 `[근무표로 이동]` 사유 텍스트와 버튼이 연결되지 않음
  - `05-sites-wizard-4.html:514-566` — W9 폼은 부모 카드에만 `aria-disabled`가 있고, 실제 입력은 native `disabled`; `[다음]`도 사유와 연결되지 않음
- 심각도: **중대**
- 사유: 지시서 §7-4는 비활성 조작 요소를 포커스 가능 `aria-disabled="true"`로 두고 항상 보이는 사유를 `aria-describedby`로 연결하도록 요구한다. 부모의 ARIA 상태는 자식 컨트롤에 상속되지 않는다.
- 수정 방향: 각 사유에 고유 ID를 부여하고 해당 조작 요소에 `aria-describedby`를 연결한다. W9 컨트롤은 명세대로 포커스 가능한 `aria-disabled` 상태를 제공하면서 클릭·Enter·Space·값 변경을 실제로 차단한다.

#### D4. W6·W9 폼 컨트롤의 프로그램상 라벨이 없음

- 파일·위치:
  - `05-sites-wizard-3.html:783-808` — W6 조 설정의 표시 이름·근무 유형·사용 여부·정원 조작
  - `05-sites-wizard-4.html:518-554` — W9 기본 설정 입력·라디오 그룹
- 심각도: **중대**
- 재현: Chromium 접근성 스냅샷에서 W6 모달의 textbox·combobox·checkbox가 이름 없이 노출됐다. 시각적 `<label>`에 `for`가 없고 컨트롤 ID/fieldset 연결도 없다.
- 사유: 지시서 §8의 입력 라벨 연결 요구와 WCAG 이름·역할·값 원칙에 미달한다.
- 수정 방향: `label[for]`+고유 ID, 라디오 그룹은 `fieldset/legend`, 토글은 연결 라벨, 정원 ± 버튼은 `정원 감소/증가` 같은 접근 가능한 이름을 제공한다. W9에도 같은 방식으로 프로그램상 라벨을 연결한다.

#### D5. W7 이탈 모달 닫기 후 포커스 복귀가 없음

- 파일·위치: `시안/2026-08-31-1차HTML/05-sites-wizard-3.html:977-1011`
- 심각도: **중대**
- 재현: `[계속 편집]`, `[변경 버리고 나가기]`, Esc는 모달을 닫지만 `closeLeaveModal()`은 `display:none`만 수행한다. 열기 트리거 또는 명시된 복귀 대상에 포커스를 돌리지 않는다.
- 사유: 지시서 §7-3의 `닫으면 연 버튼으로 복귀`를 충족하지 못해 키보드 사용자가 맥락을 잃는다.
- 수정 방향: 모달을 연 요소를 저장해 닫을 때 포커스를 복귀시킨다. 정적 W7 상태에서 실제 트리거를 만들지 않는다면 복귀할 배경 요소를 명시하고 동일하게 구현한다.
