## 6. 독립 검토 지적 판정

Terra는 helper의 `media.type ?? "image"`가 임의로 결손된 media record에서는 kind 부재를 가릴 수 있다고 지적했다. 이는 **비차단**으로 판정한다.

- 이번 계약의 명시적 fail-loud 대상은 workbook media lookup, `imageId`, media record/buffer와 지원하지 않는 extension이다.
- 설치된 ExcelJS의 타입은 media `type`을 필수로 선언하고, `Workbook.addImage`, XLSX 로더와 worksheet image model이 모두 실제 값 `type: "image"`를 생성한다.
- 이번 actual proposal/attachment1/attachment2 출력은 재로딩 뒤 `mediaKind === "image"`를 직접 단언한다.

따라서 실제 경로의 T6 증거는 유효하며, malformed mock의 missing-kind까지 새 실패 조건으로 추가하는 것은 이번 승인된 재계획 범위를 넘는다.
