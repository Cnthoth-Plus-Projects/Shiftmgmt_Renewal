3. **가짜 UI 금지** — 데이터·동작이 없는 장식 요소는 시안에 있어도 만들지 않는다. **계산 규칙이 정의되지 않은 진행률·건수 포함**
4. **실적 직접 입력 화면 금지** — 엑셀 인테이크가 유일한 경로
5. **데이터를 조용히 잘라내거나 바꾸지 않는다** — 한도 초과는 오류로 저장을 막는다
6. **forward-only** — 승인된 계산 결과를 이력 없이 덮어쓰지 않는다. 규칙 변경은 "적용 시작일" 이후 근무일에만
7. **승인과 계산은 하나의 트랜잭션**
8. **배포 엑셀 줄 순서 = 조 → 배정 순서 → 사번.** 이름순 재정렬 금지
9. **조 표시 이름과 내부 식별자를 섞지 않는다**
10. **게시(`release:publish`) 금지** — 사용자 명시 승인 없이는 절대
11. **남색 배경 금지**, 아이콘은 Material Symbols 한 세트, 문구는 전부 한국어
