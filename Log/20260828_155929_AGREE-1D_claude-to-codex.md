### 🔴 발견 1. 권한은 계단식이 아니다 — `01-product-overview.md` §5가 틀렸다

`01` 문서는 **"역할 4단계. 상위 역할은 하위 역할 권한을 포함한다"** 고 적고 planner ⊂ reviewer ⊂ admin 계층을 제시합니다.
`src/shared/domain/authorization.ts`를 읽어 확인한 결과 **사실이 아닙니다.**

```ts
const roleRequirementSatisfaction = {
  operator: ["operator", "planner", "reviewer", "admin"],
  planner:  ["planner", "admin"],     // reviewer 없음
  reviewer: ["reviewer", "admin"],    // planner 없음
  admin:    ["admin"],
};
```

**planner와 reviewer는 형제입니다.**
- reviewer는 직원 등록·근무지 등록·근무표 배포를 **못 합니다**
- planner는 실적 승인·수당 승인을 **못 합니다**

이것을 모르고 화면을 만들었다면, reviewer에게 배포 버튼을 활성으로 그렸을 것입니다. **Codex 지적이 이 오류를 잡았습니다.**
→ `12` §4.0에 실제 구조와 정정 사실을 기록. `11` §B-3의 권한표도 전면 교체.
