### 4. 추가 발견 F8~ — 합의표의 잔여 오류

**F8 — A-2가 현존하지 않는 세 번째 버튼을 요구하고 aria-disabled 적용 범위를 과도하게 좁힘.**

```html
<button type="button" class="btn-secondary" id="btn-file-cancel" autofocus>돌아가기</button>
<button type="button" class="btn-primary" id="btn-file-confirm">승인 실행</button>
```

```html
<button type="button" class="btn-danger" id="btn-exec-o10" aria-disabled="true" aria-describedby="o10-exec-desc">
```

**A-1 완료 기준 / §4.1**
