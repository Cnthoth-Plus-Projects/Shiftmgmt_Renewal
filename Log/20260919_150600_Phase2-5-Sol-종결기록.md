## 1. 판정 기준과 실제 대시보드 데이터 경로

정본 `CLAUDE.md`, `03-data-model.md` §4.2, `08-rebuild-plan.md`에 따라 V3 운영 백업과 V4 격리 복원본의 월별 대시보드 집계를 비교했다.

V3 실제 화면 경로는 다음과 같다.

1. `DashboardScreen.tsx`가 `window.appBridge.listCalculationResults()` 호출.

4. `resolveAllowanceSummaryCategory()`가 수당을 `overtime` / `substitute` / `legalHoliday`로 분류.
5. `aggregateDashboardRecords()`와 `buildDashboardTrendItems()`가 월별 분·금액을 단순 합산.

따라서 Phase 2-5의 비교 집합은 수당 승인 완료 64건만이 아니라 대시보드 API가 반환하는 실적 승인 계산 결과 **263건 전체**다.
