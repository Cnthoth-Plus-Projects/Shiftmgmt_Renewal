### 5.2 C2 — 편집 가능 값 runtime 검증

- `visible`: 반드시 존재하는 boolean. string/number/null/누락은 오류.
- `text`: 존재하면 string. 객체/배열/number/null은 오류.
- `logoAssetId`: 존재하면 `null` 또는 trim 후 비어 있지 않은 안전한 ID string. 경로 구분자, NUL/control, 공백뿐인 값은 오류.
- `columnWidths`: 존재하면 plain object. key는 비어 있지 않은 string, 값은 finite `> 0` number. 배열/null/NaN/Infinity/0/음수/문자는 오류.
- `font`: 존재하면 plain object. family는 비어 있지 않은 string, sizePt는 finite `> 0`; bold/italic은 존재하면 boolean; color는 기존 `#RRGGBB`/`#AARRGGBB`; unknown key는 오류.
- 보호 값은 baseline 비교와 타입 검증을 둘 다 한다. normalize/clamp/delete 후 수락하지 않는다.

최소 안정 issue code: `INVALID_BLOCK_VISIBILITY`, `INVALID_BLOCK_TEXT`, `INVALID_LOGO_ASSET_ID`, `INVALID_COLUMN_WIDTHS`, `INVALID_FONT_BOLD`, `INVALID_FONT_ITALIC`.

### 5.4 C4 — 파일명 패턴 완전 검증
