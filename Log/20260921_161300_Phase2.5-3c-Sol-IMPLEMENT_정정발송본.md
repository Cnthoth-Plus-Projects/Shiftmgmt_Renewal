### 6.3 artifact 계약 세부사항

- runtime 공개 지원 키는 정확히 다섯 개다: `schedule-xlsx/template1`, `schedule-xlsx/template2`, `proposal-xlsx`, `attachment1-xlsx`, `attachment2-xlsx`.
- `DocumentKind`의 PDF union은 최종 계약을 위해 유지하지만 list에 나오지 않는다. get/save/reset/preview/history에 PDF key를 직접 주면 해당 route failure code로 실패한다. placeholder, 빈 snapshot, fake URL을 만들지 않는다.
- preview는 input definition의 key로 현재 `DocumentLayoutSnapshot.activeRevisionId`를 조회하고 `basedOnRevisionId`와 생성 시작 전에 정확 비교한다. 불일치하면 generator·mkdir·activity 모두 0이어야 한다.
- `previewId`는 production에서 `crypto.randomUUID()`다. URL은 상대 URL `/api/document-layout-previews/<previewId>/<memberId>`만 반환한다.
- artifact root는 `os.tmpdir()` 아래 전용 디렉터리다. repository, `dataDir`, business DB에는 어떤 manifest나 파일도 쓰지 않는다.
- 만료는 생성 성공 시각부터 정확히 10분이며 각 output의 `expiresAt`은 같은 ISO 시각이다.
- manifest에는 서버 생성 UUID, 만료 시각, memberId, media type, 안전한 상대 파일명만 둔다. 클라이언트 경로, 임의 절대 경로, `..`를 저장하거나 받지 않는다.
- resolver는 exact UUID/member/manifest mapping만 허용한다. 만료면 실제 삭제 성공 여부와 무관하게 먼저 404 대상이 되고 정리를 시도한다.
- 생성 실패 시 부분 디렉터리 정리를 시도하되 cleanup 실패가 원래 실패를 성공으로 바꾸거나 덮지 않는다.
- production POST route와 GET route는 같은 singleton manifest를 공유한다. test는 clock/root/id/generator/current-layout/resolver를 주입할 수 있어야 한다.

### 6.4 최소 변경 원칙

- 요구사항과 직접 연결되지 않은 정리·이름 변경·포맷 변경을 하지 않는다.

## 7. 적용할 불변조건과 과거 함정

### 7.1 필수 불변조건

- 관리자 권한은 manifest 선언만 믿지 않고 route registry 및 binary GET 양쪽에서 실제 차단돼야 한다.
- `source_path=''`인 layout 행만 기존 storage service가 다루게 하고 old file-template 행은 읽거나 바꾸지 않는다.
- save/reset revision conflict는 기존 transaction/history 계약을 그대로 보존한다.
- 미리보기는 실제 built-in Excel generator만 사용한다. AI·인터넷·외부 API·업로드 양식 파일을 사용하지 않는다.
- Pool/BP/사번 없는 비BP 지급 제외 등 수당·내보내기 기존 불변식은 보호 28파일 무변경과 전체 시험으로 보존한다.
- 오류에는 내부 절대 경로나 영문 기술 stack을 사용자 메시지로 새로 노출하지 않는다.

### 7.2 반드시 피할 과거 실패

- PDF union이 있다는 이유로 미구현 PDF를 list하거나 placeholder로 성공시키기.
- preview URL 대신 filesystem path를 반환하거나 repo/dataDir에 temp 파일을 쓰기.
- stale revision을 generator 실행 뒤 확인해 파일이 남게 하기.
- auth 실패 후 service/generator/activity가 실행되게 하기.
- old 10 중 일부만 제거해 manifest/bridge/registry 수가 어긋나게 하기.
- `operations:select-migration-file`까지 선행 제거해 2.5-6 범위를 침범하기.
- 기존 `server.test.ts` helper로 binary body를 UTF-8 string 변환해 byte 손상을 놓치기.
- 짧은 SHA, 추측한 SHA, 실행하지 않은 명령을 증거로 쓰기.
