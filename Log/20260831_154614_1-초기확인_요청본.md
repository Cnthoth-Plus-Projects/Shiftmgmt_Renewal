## 결과물 규격

```
- HTML 3파일. 폭 1440px 고정, 뷰포트 1440 × 900 기준
- 각 파일 = 앱 껍데기(좌측 메뉴 + 상단 제목줄 + 하단 상태줄)를 포함한 창 전체
- 🔴 상태를 세로로 이어 붙이고 상태마다 회색 라벨 바를 답니다
     탭·해시로 갈아 끼우지 않습니다 — 스크롤만 내리면 25상태가 전부 보여야 검수가 됩니다
- CSS는 각 HTML 안에 <style>로 인라인. 공통 CSS 파일 만들지 않습니다
- 외부 파일 참조 금지 (예외: Material Symbols 아이콘 폰트 CDN 1개, 실패해도 안 깨지게)
- 표는 최소 17행을 한국어 샘플 데이터로 채웁니다
- 모든 문구 한국어
```

## 실제로 동작해야 하는 것 5가지

| # | 동작 |
|---|---|
| 1 | **Tab 이동** — 메뉴 → 탭 → 필터 → 표 → 버튼. 포커스 링이 눈에 보일 것 |
| 2 | **표 키보드** — ↑↓ 행 이동, Space 선택, Enter 상세 열기 |
| 3 | **모달** — 포커스가 모달 안에 갇힘, Esc로 닫힘, 닫으면 원래 버튼으로 복귀 |
| 4 | **비활성 버튼** — `aria-disabled="true"`. 포커스는 가되 눌리지 않음. 사유를 `aria-describedby`로 연결 |
| 5 | **승인(되돌아오는 방식)** — 승인하면 배지가 `대기`→`승인`, 상단 건수 갱신, 포커스가 다음 미처리 행으로, `aria-live` 영역 문구 변경. **페이지를 새로 열면 원래대로 복귀** |

🔴 `window.confirm` · `alert` · `prompt` 금지. 확인이 필요하면 **화면 안에 그린 모달**을 씁니다.

# 🔴 반드시 지켜야 하는 것 (실제 사고에서 나온 규칙)

1. **가짜 UI 금지** — **"이걸 누르면 무슨 일이 일어나고, 그 데이터는 어디서 오는가?"** 에 답할 수 없으면 만들지 않습니다. **시안에 있어도** 만들지 않습니다
2. **실적을 화면에서 직접 입력하는 기능은 없습니다.** 엑셀 회수가 유일한 경로입니다
3. **모든 화면에 다섯 상태** — 로딩 / 빈 상태 / 오류 / 권한 없음 / 처리 중. **빈 상태는 "없습니다"가 아니라 다음에 뭘 하면 되는지** 안내합니다. **권한 없음은 숨기지 말고 비활성 + 이유 표시**
4. **문구는 전부 한국어.** 영문 기술 용어·에러 코드 노출 금지. 오류는 "무엇이 잘못됐고 무엇을 하면 되는지"까지
5. **색만으로 구분하지 않습니다** — 색 + 글자 병기
6. **날짜는 고르는 즉시 반영.** `[확인]`·`[적용]` 버튼 금지 (엉뚱한 날짜가 저장된 사고의 원인)
7. **직급은 `사원 / 대리 / 과장 / 차장 / 부장` 5개 선택 목록만.** 다른 값은 저장 시 버려져 결재 서류에 `-`로 나옵니다
8. **아이콘은 Material Symbols 한 세트.** **남색 배경 금지**(가독성)
9. **되돌릴 수 없는 동작**(실적 승인 · 품의 승인 · 근무표 게시 · DB 교체)에는 **확인 단계 + 중복 클릭 차단**
10. **`N/M` 숫자 진행률은 「엑셀 접수·해석」과 「프로그램 업데이트」 두 곳에만.** 그 밖은 `처리 중…`, **중단 버튼 없음**
11. **한 파일 30KB를 넘기지 않게 쪼갭니다** (기존 화면 123KB의 재발 방지)
