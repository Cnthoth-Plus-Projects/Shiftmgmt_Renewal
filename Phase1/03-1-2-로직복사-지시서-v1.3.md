### D-3. `allowance-document-pdf-service.ts` 는 **복사**하고, `electron` 이라는 이름은 **자리 패키지**로 푼다
- **왜 뺄 수 없나**: `allowance-document-export-service.ts:44` 가 `import { writeAllowancePdfDocuments } from "./allowance-document-pdf-service";` 로 **정적으로** 부르고, 그 export-service 를 다시 `allowance-proposal-approval-service.ts:14` 가 부른다 — **🔴 절대 규칙 1 의 승인 경로**다. 실측으로 이 3개가 전부 깨졌다(§0-다).
- **electron 접촉은 딱 2곳**(1,903줄 중): `:4` `import { nativeImage } from "electron";`(로고 이미지 `:455`·`:523`) · `:850` `await import("electron")` → `BrowserWindow` → `printToPDF`(`:869`). `:846` 의 `if (!process.versions.electron) throw` 가드 때문에 **동적 import 는 형태 ①에서 실행되지 않는다.** 문제는 **정적 import(:4)** 뿐이고, 모듈을 불러오는 순간 터진다.
- **해결(실측 검증됨)**: 저장소 안 자리 패키지 `vendor/electron-compat/`(3파일)를 `package.json` 에 `"electron": "file:./vendor/electron-compat"` 로 건다. **타입검사도 실행도 한 번에 풀린다.**

  - **`tsconfig.server.json`·`vitest.config.ts` 를 고칠 필요가 없다**(실측).
  - **`allowance-document-pdf-service.ts` 자체는 한 글자도 고치지 않는다** — 조치는 전부 그 파일 **바깥**이다(절대 규칙 11 준수).
