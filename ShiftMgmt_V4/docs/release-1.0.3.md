# 교대근무관리 시스템 1.0.3

공휴일 동기화와 주말 공휴일 시간 적용, 일부 요율 누락 방어를 보완한 새 PC 첫 설치용 Windows x64 패키지입니다. Node24를 포함하며 Google Chrome은 별도로 필요합니다.

- 운영 관리 → 공휴일에서 ‘한국 공휴일 동기화’를 누르면 좌측 등록 목록을 유지한 채 우측에 미리보기를 표시합니다. ‘적용하기’를 눌러야 선택 연도에 저장합니다. 기존 목록에만 있는 날짜는 자동 삭제하지 않습니다.
- 기본 공휴일 API의 원 공휴일·대체일 누락을 Google 대한민국 공휴일 일정으로 보완합니다. 기념일은 제외하며, 보완 자료가 없는 연도와 통신·형식 오류에서는 저장하지 않습니다. 임시공휴일 등 최신 지정 내용은 적용 전 확인해 주세요. 사용자 지정 JSON API도 계속 지원합니다.
- 공휴일과 토·일이 겹치면 기존 편성은 유지하고 해당 요일의 설정 시간을 사용합니다. 수당은 DB 공휴일과 근무일 요율을 따릅니다. 일반 주말 편성만으로 공휴일 수당을 만들지 않으며 날짜 예외·휴무·0분을 보존합니다.
- 기본·연장·야간 중 실제 근무분이 있는 축에 요율이 빠졌다면 일부 금액만 지급하는 승인도 차단합니다. 안내에 표시된 요율 항목을 수정한 뒤 다시 승인해 주세요. 실제분이 없는 축과 읽기 전용 영향도 비교의 0배율은 허용합니다.

이미 승인된 금액·정책 스냅샷과 취소 전 기록은 자동 정정하지 않습니다. 시급 변경 후 미승인 실적의 자동 갱신과 동일일 정정 이력은 유지합니다. 품의서·별첨1·별첨2는 A4 출력용이며 근무표는 Excel 파일로 만듭니다.

[새 PC 설치 안내](fresh-install.md)에 따라 ZIP을 풀어 INSTALL.cmd를 실행합니다. 기존 설치·자료는 덮어쓰지 않습니다. 라이선스·SHA256SUMS·매니페스트·BUILD_RECEIPT를 함께 확인해 주세요. 이 ZIP은 Windows 코드서명된 설치 프로그램은 아닙니다.

공개 게시와 실제 대상 PC 설치 전의 초안입니다. 소스 커밋·검증 결과·ZIP 해시는 첨부 검증 기록으로 고정합니다. 기존 1.0.2 ZIP과 기록은 보존합니다.
