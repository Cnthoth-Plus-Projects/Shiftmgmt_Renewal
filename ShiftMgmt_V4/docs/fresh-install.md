# 새 PC에 처음 설치하기 — 1.0.0

이 배포물은 Windows x64 PC 한 대에서 사용하는 교대근무관리 시스템입니다. Node 실행 환경을 포함하므로 Node나 npm을 따로 설치할 필요가 없습니다. Google Chrome은 미리 설치해 주세요. ARM 및 32비트 Windows용 설치 파일은 아닙니다.

1. ZIP과 SHA256SUMS.txt를 같은 릴리즈에서 받습니다. PowerShell의 Get-FileHash -Algorithm SHA256 명령으로 ZIP의 해시가 목록과 같은지 확인합니다.
2. ZIP을 마우스 오른쪽 버튼 → 모두 압축 풀기로 풉니다. ZIP 안에서 바로 실행하지 마세요.
3. 압축을 푼 폴더의 INSTALL.cmd를 두 번 클릭합니다. 관리자 권한은 필요 없습니다. 성공하면 바탕 화면에 ‘교대근무관리 시스템’ 바로가기가 생깁니다.
4. 바로가기를 실행합니다. 실행 창에 표시되는 admin 아이디와 PC에서 새로 생성한 임시 비밀번호로 로그인합니다. 처음 로그인하면 비밀번호 변경 화면이 먼저 나옵니다. 비밀번호는 대문자·소문자·숫자·특수문자를 포함한 8자 이상으로 정해 주세요.
5. 프로그램의 운영 관리에서 계정과 연락처, 폴더·백업 위치, 요율·정책 적용일을 실제 업무 기준에 맞게 확인하고 인력·근무지를 등록합니다. 기본 계정의 연락처는 예시입니다. 운영담당 계정은 필요한 경우 관리자가 비밀번호를 재설정해 전달하고, 승인담당 계정은 사용 여부를 확인한 후 승인합니다.

실행 창은 작업하는 동안 열어 두세요. 종료할 때는 실행 창에서 Q를 입력하고 Enter를 누릅니다. 크롬 화면을 닫는 것만으로 서버가 종료되지는 않습니다. 다음 실행도 같은 바로가기를 사용합니다.

프로그램은 %LOCALAPPDATA%\Programs\ShiftMgmt_V4 에 설치됩니다. 자료는 프로그램과 별도로 %LOCALAPPDATA%\ShiftMgmt_V4 에 보관되며, 그 아래 data 폴더에 DB와 가져오기/내보내기/백업 폴더가 생성됩니다. 자료 폴더를 지우면 업무 자료가 사라집니다. 임시 비밀번호 파일은 첫 비밀번호 변경 후 해당 계정 정보가 제거됩니다.

기존 설치 폴더, 자료 폴더 또는 같은 이름의 바로가기가 있으면 설치는 중단됩니다. 기존 자료를 삭제해서 해결하지 마세요. 이 패키지는 기존 PC 업데이트나 V3 데이터 이관용이 아닙니다. 설치 실패 시 임시 복사 폴더만 정리하고 기존 자료는 건드리지 않습니다. 바로가기 생성만 실패한 경우 표시된 설치 폴더의 START.cmd를 실행할 수 있습니다.

처음에는 실제 업무 인력·실적·승인·수당 자료가 없는 상태로 시작합니다. 설치 파일에 운영 DB나 실적 엑셀은 포함하지 않습니다. 요율 등 초기 기준값은 실제 운영 전에 확인해야 합니다.

품의서·별첨1·별첨2만 A4로 출력합니다. 근무표 샘플과 근무표는 Excel 파일로 생성합니다.

백업은 운영 관리의 백업 기능으로 생성하고 프로그램 폴더 밖의 별도 저장소에도 보관해 주세요. JSON3 백업에는 승인 취소 전 기록이 포함되므로 구판 프로그램에서 복원할 수 없습니다. 기존 PC로 교체·이관하거나 구판으로 돌아가는 작업은 별도 확인과 백업이 필요합니다.

시작하지 못하면 실행 창의 안내를 먼저 확인합니다. 크롬이 없다면 크롬을 설치하고 다시 실행합니다. 이미 실행 중이라는 안내가 나오면 기존 실행 창을 확인합니다. 이 프로그램은 로컬 주소 http://127.0.0.1:8734 에서만 동작합니다. 다른 PC에서 접속하는 서버나 자동 업데이트 기능은 제공하지 않습니다.

제거하려면 Q로 종료한 후 프로그램 설치 폴더와 바탕 화면 바로가기만 삭제합니다. 자료 폴더는 백업을 확인하기 전까지 보관하세요.

ZIP의 SHA256과 파일 매니페스트는 배포 파일의 손상·변경을 확인하기 위한 것입니다. Windows 코드서명된 설치 프로그램은 아닙니다. 실행 전 ZIP은 프로젝트의 공식 릴리즈에서 받아 주세요.
