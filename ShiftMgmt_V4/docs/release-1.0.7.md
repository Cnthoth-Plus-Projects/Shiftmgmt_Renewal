# 1.0.7 — 회사 아이콘 적용

- 기존 회사 로고의 파란 심벌을 투명 배경 ICO/PNG로 변환했습니다. Windows ICO는 16·24·32·48·64·128·256px를 포함합니다.
- 바탕화면/시작 메뉴 바로가기, 시작 창, 알림 영역, 브라우저 탭, 향후 설치 EXE/제거 목록에 회사 아이콘을 사용합니다.
- 현재 PC는 백업 후 로컬 검증판으로 적용합니다. 공개 GitHub Release를 발행한 것은 아닙니다.

자동업데이트는 실행할 때 더 높은 정식 Release의 배포 ZIP을 확인·검증하는 기존 방식입니다. 소스 코드 push만으로 배포되지 않습니다. 자료 호환성이 맞는 버전만 자동 적용하고 실패하면 사용 가능한 기존 버전으로 시작합니다. 기존 DB·업무 자료·계정은 유지합니다.
