# 1.0.6 — 시작 안내와 업무 파일 접근 개선

- 바탕화면 실행은 콘솔 대신 회사 로고·준비 단계·진행률 바가 있는 Windows 시작 창을 사용합니다. 준비가 끝나면 프로그램 화면을 열고 시작 창을 숨깁니다. 알림 영역의 교대근무관리 아이콘에서 프로그램 열기/상태 보기/종료를 사용할 수 있습니다.
- 진행률은 실제 준비 단계의 완료를 기준으로 표시합니다. 초기 로그인 정보가 있는 새 설치는 안내 버튼을 제공합니다. 오류는 시작 창에 표시하고 실행 기록을 확인할 수 있습니다.
- 품의·문서 출력의 문서 상세에서 각 문서의 저장 폴더를 열 수 있습니다. 경로 복사는 유지합니다. 폴더가 이동/삭제되었거나 접근할 수 없으면 해당 위치에 안내합니다.
- 실적 접수 현황의 원본 누락 안내를 요약 카드와 펼칠 수 있는 근무지·근무월 목록으로 바꿨습니다. 모든 서로 다른 안내는 상세에 유지하며, 다른 문제는 별도 목록으로 구분합니다. 원본 누락을 해결하거나 실적·승인·수당을 삭제하는 변경은 아닙니다.

현재PC 적용은 로컬 검증판입니다. 기존 1.0.5 프로그램과 자료 백업을 보존합니다. 기존 실행 창이 열려 있다면 종료한 뒤 새 바로가기로 실행하세요. 공개 릴리즈 여부와 다릅니다.
