# 교대근무관리 시스템 1.0.4

기존 ShiftMS 0.5.8 JSON을 가져오는 기능과 승인완료 원본 조회를 보완하고, 프로그램 실행 시 자동업데이트를 추가했습니다. Windows x64용이며 Node 실행 환경을 포함합니다. Google Chrome은 별도로 필요합니다.

- **JSON 이관:** 구판 0.5.8의 39표 JSON을 직접 편집하지 않고 복원합니다. 구판 임시 재분석 상태를 처리하고, 설정을 저장하기 전의 첫 백업과 교체 전 자동 백업도 다시 복원할 수 있습니다. 승인 금액·계산·이력은 자동 재계산하지 않습니다.
- **승인완료 원본:** 과거 Excel을 새 PC의 승인완료 폴더에 연도·월 구조로 복사하면, 이전 경로가 없고 원본 실적이 일치하는 유일한 보관본을 기존 승인 기록에 연결합니다. 근무월·근무일과 날짜 검색으로 찾아 원본을 열 수 있습니다. 중복·불일치·접근 불가 파일은 자동 연결하지 않습니다.
- **자동업데이트:** 1.0.4 설치 이후에는 바탕 화면 바로가기로 실행하면 호환되는 새 정식 버전을 확인·다운로드·검증합니다. 새 버전이 정상 시작된 뒤 적용하고 DB·업무 자료는 그대로 사용합니다. 통신·검증·시작 실패 시 기존 버전으로 실행합니다. 실행 중에는 업데이트하지 않습니다. DB 구조가 바뀌는 버전은 별도 설치·이관 안내를 따릅니다.
- **Excel 생성:** 내장 양식 1·2로 새 근무표를 생성하므로 과거 템플릿 파일이 필요하지 않습니다. 이미 작성한 Excel 원본은 JSON에 들어 있지 않으므로 별도 복사합니다. 품의서·별첨1·별첨2는 A4 출력용입니다.

`ShiftMgmt-1.0.4-Setup-x64.exe`를 다운로드해 설치하고 [새 PC 설치·JSON 복원 안내](fresh-install.md)를 따라 진행하세요. 처음 로그인하면 비밀번호를 변경합니다. JSON 복원 후 계정도 구판 계정으로 바뀌므로 기존 PC의 아이디·비밀번호를 사용하세요.

원본 JSON과 업무 파일을 보존하고 복사본으로 시험합니다. 복원 후 인력·근무지·시급 이력·근무표, 월별 승인 건수·수당 합계, 재시작 후 로그인과 과거 원본 열기를 대조하세요. 실제 운영 자료에 대한 최종 확인은 사용자가 진행합니다. 개발 시험용 이관 결과와 설치 검증 기록은 릴리즈 첨부 파일로 제공합니다.
