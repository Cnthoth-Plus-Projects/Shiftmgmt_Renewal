# 교대근무관리 시스템 1.0.1

근무표 생성·배포에서 실적 접수·승인으로 이어지는 경로의 정확성을 보완했습니다. 1.0.0 초안을 대체하는 새 PC 첫 설치용 Windows x64 패키지입니다. Node24를 포함하며 Google Chrome은 별도로 설치해야 합니다.

- 연장근무 시작/종료의 ‘시’가 비어 있으면 0시로 바꾸지 않고 오류로 처리해 승인을 막습니다. 명시적 자정과 유효한 시각의 분 생략(정시)은 유지합니다.
- 파일명과 엑셀 본문의 근무월이 다르거나 실제 근무일이 대상 월 밖이면 접수 오류를 표시합니다. 구판 캐시도 승인 시 월을 다시 확인하며, 원본이 변경되거나 권한이 사라지면 승인·계산을 저장하지 않습니다.
- 기본 배포 위치는 근무표 내보내기 폴더 아래 ‘배포’입니다. 실적 승인 보관 폴더와 분리하며, 승인완료 표시는 실제 승인·계산 기록이 있는 행에만 적용합니다. 과거 배포본과 반복 배포본도 실제 실적 승인으로 취급하지 않습니다.
- 기존 승인·계산 이력과 정책 적용일·수당 산식은 보존합니다. 과거에 잘못 접수·승인된 자료를 자동 삭제하거나 재계산하지 않습니다. 월 충돌이 있는 과거 행은 조회 시 오류 안내로 확인할 수 있습니다.

새 PC에서는 ZIP을 압축 해제하고 INSTALL.cmd를 실행한 다음 바탕 화면 바로가기를 사용합니다. 최초 admin / 1234 로그인 후 비밀번호를 변경해야 합니다. 자세한 내용은 [새 PC 설치 안내](fresh-install.md)를 확인해 주세요.

이 패키지는 기존 설치나 데이터가 있으면 덮어쓰지 않습니다. 기존 PC 업데이트·이관·구판 복귀는 별도 백업과 확인이 필요합니다. 공개 게시와 실제 대상 PC 적용은 별도 단계입니다. 1.0.0 초안은 새 설치에 사용하지 마세요.

품의서·별첨1·별첨2는 A4로 출력하고 근무표 샘플과 근무표는 Excel로 생성합니다. 설치 ZIP은 Windows 코드서명된 설치 프로그램이 아니며 SHA256SUMS와 파일 매니페스트를 함께 확인해야 합니다. Node와 글꼴·실행 의존성 라이선스는 ZIP에 포함됩니다.

최종 검증 결과·소스 커밋·ZIP 해시는 첨부 BUILD_RECEIPT 및 검증 기록에 고정합니다. 유지보수자는 고정된 커밋의 ShiftMgmt_V4 폴더에서 npm ci, npm run release:check, npm run release:package -- [새 출력 폴더], npm run release:smoke -- [ZIP 절대 경로] 순서로 검증할 수 있습니다.
