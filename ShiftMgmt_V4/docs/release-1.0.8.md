# 1.0.8 — 회사 디자인·복원 안내 개선 및 자동업데이트 확인

1.0.4 이후 현재 PC에서 확인한 개선 사항을 정식 배포합니다. 설치된 1.0.7에서는 프로그램을 완전히 종료한 뒤 기존 바탕화면 바로가기로 실행하면 1.0.8을 확인·다운로드·검증하여 같은 자료 폴더로 시작합니다.

- 회사 로고와 파란 심벌 아이콘을 로그인·메뉴·시작창·바로가기·알림 영역·브라우저 탭에 적용했습니다. 시작창에 준비 단계·진행률·오류 안내를 표시하고 알림 영역에서 프로그램을 열거나 종료할 수 있습니다.
- JSON 복원 미리보기를 별도 모달로 구성하고, 교체 입력·확인 버튼·완료 후 로그인 안내를 정돈했습니다. 구판의 사번 없는 과거 기록은 별도로 보존하며, 관리자에게 실제 사번을 확인해 한 번 연결하는 화면을 제공합니다. 기존 승인 금액과 계산 이력을 유지합니다.
- 품의·문서 출력의 문서 상세에 저장 폴더 열기를 추가했습니다. 실적 접수 현황의 원본 누락 안내는 요약과 펼칠 수 있는 전체 목록으로 확인할 수 있습니다.
- 실행 버전 표시와 대시보드 순위 목록의 공간 활용을 개선했습니다.

업데이트는 프로그램을 실행할 때 확인합니다. 실행 중인 업무 화면에 즉시 적용되지는 않습니다. 배포 파일과 자료 호환성을 검증하며, 다운로드나 새 버전 시작에 문제가 생기면 사용 가능한 기존 버전으로 실행합니다. 기존 DB·계정·업무 자료 폴더를 유지하므로 JSON을 다시 복원할 필요가 없습니다.

새 PC는 `ShiftMgmt-1.0.8-win-x64.zip`을 별도 폴더에 압축 해제하고 `INSTALL.cmd`로 설치합니다. Google Chrome이 필요하며 Node 실행 환경은 포함되어 있습니다. 설치·이관 절차는 ZIP의 설치안내를 확인해 주세요.
