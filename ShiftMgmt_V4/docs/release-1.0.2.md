# 교대근무관리 시스템 1.0.2

근무일에 맞는 요율 선택과 원 단위 계산을 보완한 새 PC 첫 설치용 Windows x64 패키지입니다. 1.0.0·1.0.1 초안을 대체하며 Node24를 포함합니다. Google Chrome은 별도로 설치해야 합니다.

- 요율은 근무일이 포함되는 적용 기간으로 선택합니다. 기간이 명확한 과거 종료 버전도 해당 기간의 실적에 사용합니다. 미래·초안 요율이나 기간에 맞지 않는 다른 연도 요율로 대신 계산하지 않습니다. 적용 요율이 없으면 승인을 중단합니다.
- 미래 요율을 활성화해도 현재 요율의 적용 기간을 보존하고, 앞 요율의 종료일을 새 시작일 전날까지로 정리합니다. 같은 시작일의 중복 적용은 막습니다. 요율 목록에는 현재 적용·적용 예정·기간 종료를 표시합니다.
- 공휴일에 추가로 일한 연장근무도 요율 관리의 휴일 연장·야간 배율로 계산합니다. 실제 근무가 있는데 적용 배율이 모두 0이면 승인·계산을 저장하지 않고 안내합니다. 초기 배율 0을 운영 기준에 맞게 확인한 뒤 다시 승인해 주세요. 이 버전이 운영 배율을 임의로 정하지 않습니다. 일반 토·일을 공휴일로 자동 분류하는 변경은 포함하지 않습니다.
- 십진수 시급과 배율을 정확하게 계산해 불필요한 1원 올림을 방지합니다. 예를 들어 시급 14,100원 × 1시간 × 1.1배는 15,510원입니다. 실적별 총액 올림과 라인 잔여 배분 방식은 유지합니다. 보조 미리보기도 저장된 해당 기간 요율로 계산합니다.
- 기존 승인·계산 원문과 금액은 요율 변경, 재읽기, 재시작으로 자동 수정하지 않습니다. 과거의 잘못된 승인 금액도 일괄 재계산하지 않으며 기존 승인 취소·원본 정정·재승인 절차로 확인해야 합니다.

새 PC에서 ZIP을 압축 해제하고 INSTALL.cmd를 실행한 다음 바탕 화면 바로가기로 시작합니다. 첫 admin / 1234 로그인 후 비밀번호를 변경합니다. [새 PC 설치 안내](fresh-install.md)를 확인해 주세요. 기존 설치나 데이터가 있으면 덮어쓰지 않습니다. 기존 PC 업데이트·이관·구판 복귀는 별도 백업과 확인이 필요합니다.

품의서·별첨1·별첨2는 A4 출력용이고 근무표는 Excel 파일로 생성합니다. ZIP은 Windows 코드서명된 설치 프로그램이 아니며 SHA256SUMS·매니페스트·BUILD_RECEIPT를 함께 확인해야 합니다. 라이선스는 ZIP에 포함됩니다.

공개 게시와 실제 대상 PC 설치 전의 초안입니다. 최종 검증 결과와 소스 커밋·ZIP 해시는 첨부 검증 기록에 고정합니다. 유지보수자는 고정 커밋의 ShiftMgmt_V4에서 npm ci, npm run release:check, npm run release:package -- [새 출력 폴더], npm run release:smoke -- [ZIP 절대 경로] 순서로 검증할 수 있습니다.
